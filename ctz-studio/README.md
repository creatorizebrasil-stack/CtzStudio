# CTZ Studio

Aplicacao web estatica para criar, personalizar, salvar e exportar carrosseis para redes sociais.

## Executar localmente

Dê dois cliques em `iniciar-app.cmd`. O aplicativo abrirá em
`http://localhost:4173`, evitando as restrições do modo `file://`.

Para validar o pacote antes do deploy:

```sh
npm run build
```

## Deploy

O projeto inclui `vercel.json` e pode ser importado diretamente pela Vercel sem diretorio de build.
